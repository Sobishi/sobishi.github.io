HOW I BUILD

From problem → data → system → decision.

My approach to projects starts with the operational problem rather than the technology.

First I define the decision that needs to be made. Then I identify the data required, analyse the root cause, design the process or system and finally determine how technology can make the decision faster, more reliable or more scalable.
